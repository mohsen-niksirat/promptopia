پرامپت فارسی

Создайте ультрареалистичный студийный портрет молодого мужчины с полностью новым, уникальным лицом (не похожим ни на одного реального человека). Формат кадра 9:16, вертикальный, по грудь. Композиция должна быть идентичной референсу: — корпус слегка развернут вправо; — голова повернута влево примерно на 35–45 градусов; — взгляд направлен влево, не в камеру; — спокойное, уверенное выражение лица; — губы слегка сомкнуты; — плечи расслаблены; — кадр построен по правилу третей, с небольшим свободным пространством сверху. Внешность: — густые тёмные волосы с ровным коротким French Crop (низкий fade); — густые естественные брови; — выразительные карие глаза; — прямой нос; — чёткая линия нижней челюсти; — лёгкая короткая щетина; — оливковый оттенок кожи; — максимально реалистичная текстура кожи с видимыми порами, микрорельефом, лёгкими несовершенствами и естественным блеском. Одежда: — свободная молочно-белая фактурная футболка без принтов; — короткие широкие рукава с необработанным краем; — тонкая золотая цепочка на шее. Освещение: — профессиональный студийный свет; — мягкий тёплый key light слева спереди; — лёгкий заполняющий свет справа; — мягкие естественные тени; — кинематографическая цветопередача; — высокий динамический диапазон. Фон: — однотонный матовый тёмно-терракотовый (бордово-красный) градиент; — полностью чистый, без текстур, без предметов и без надписей. Качество: — hyper realistic; — photorealistic; — ultra detailed; — editorial fashion portrait; — luxury studio photography; — 8K; — HDR; — сверхдетальная текстура кожи; — естественная цветокоррекция; — профессиональная оптика 85mm; — f/2.0; — мягкое боке; — без шума; — без водяных знаков; — без текста; — без логотипов.
