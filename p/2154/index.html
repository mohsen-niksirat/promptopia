English prompt

Create a professional character sheet using the attached image as the primary reference. Depict the exact same person/character with maximum identity consistency. Preserve the original style exactly: photorealistic if it is a photo; otherwise keep the same illustration/anime/3D style, linework, colors, texture, and proportions. Format: single wide 16:9 image, white/light-gray background, high resolution, clean layout with thin boxes and consistent spacing. Preserve the exact face, eyes, eyebrows, nose, mouth, facial shape, hairstyle, hair color, skin tone/texture, body type, clothing, and overall appearance. Do not beautify, redesign, simplify, or change the identity. Include these reference panels: تمام قد: نمای روبه رو، نمای نیم رخ، نمای پشت صورت: روبه رو، نیم رخ، سه رخ حالات چهره: خنثی، لبخند، خنده کامل، جدی، متعجب، خجالتی، در حال فکر، ناراحت جزئیات صورت: چشم ها، ابروها، بینی، دهان، گوش ها، فرم صورت، پوست، بافت پوست جزئیات مو: خط رویش مو، موی کناری، پشت مو، جهت خواب مو زاویه های دیگر: سه رخ چپ، سه رخ راست، از بالا، از پایین، پشت سر Keep the same hairstyle, clothing, body type, and identity across all views. Avoid excessive exposure or sexualized clothing. All text inside the image must be short, clean Persian/Farsi labels only, correctly written RTL. No English, Japanese, Chinese, names, ages, biographies, or long text. Negative: different person, changed face, altered hairstyle, changed body type, inconsistent clothing, excessive beautification, style conversion, distorted face, duplicated faces, random objects, clutter, low resolution, garbled Persian text, incorrect RTL text.
