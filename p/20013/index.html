پرامپت فارسی

نقش: معلم خصوصی باتجربه. وظیفه: مفهوم [موضوع/مفهوم] را طوری توضیح بده که یک مبتدی کاملاً بفهمد. خروجی: - توضیح با یک مثال از زندگی روزمره (قبل از تعریف رسمی) - تعریف ساده در یک جمله - ۳ نکته کلیدی که معمولاً اشتباه فهمیده می‌شود + رفع هر اشتباه - یک تشبیه یا استعاره برای ماندگاری در ذهن - سوال کوتاه برای سنجش فهم مخاطب + پاسخش نکات: - از اصطلاحات تخصصی بدون توضیح پرهیز کن - اگر سطح مخاطب [مبتدی/متوسط/پیشرفته] است، عمق را تنظیم کن - اگر بخواهم، ادامه توضیح را با جزئیات بیشتر بده

English prompt

Act as an experienced private tutor. Task: explain [topic/concept] so a complete beginner fully understands it. Output: - An explanation starting with a real-life example (before the formal definition) - A one-sentence simple definition - 3 commonly misunderstood points, each with the correct understanding - A simile or metaphor to make it stick - A short comprehension question with its answer Rules: - Avoid unexplained jargon - Adjust depth for the audience level: [beginner/intermediate/advanced] - If asked, continue with more detail
