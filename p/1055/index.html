پرامپت فارسی

A 2D cartoon character with the EXACT FACIAL IDENTITY, identical face shape, same hairstyle, and exact facial features as the reference photo. The character is drawn STRICTLY in the iconic Rick and Morty animation style. Flat 2D cartoon rendering, clean uniform outlines, asterisk-style pupils, minimal detail, solid flat colors, absolutely no 3D rendering, no realistic skin texture, no gradients. The character is in a dynamic, expressive pose natural to the Rick and Morty universe (like panicking, pointing, or looking confused). Absolutely NO text, no letters, no watermark. --no text, typography, 3d, realistic realism, shading, gradients --ar 4:5 --stylize 50
