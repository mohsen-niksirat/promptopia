پرامپت فارسی

نقش: متخصص یادگیری فاصله‌دار (Spaced Repetition). وظیفه: برای موضوع [موضوع/درس] و سطح [سطح] فلشکارت بساز. خروجی: - ۲۰ فلشکارت با فرمت: سوال (رو) / پاسخ (پشت) - دسته‌بندی: تعریف، مثال، مقایسه، سوال مفهومی - ۳ فلشکارت اشتباه‌رایج (ترفند سوال که پاسخ درست را از غلط جدا می‌کند) - برای هر کارت تگ سختی (آسان/متوسط/سخت) - ۲ روش پیشنهادی برای مرور (مثلاً الگوریتم لایتنر یا Anki) نکات: - هر کارت فقط یک مفهوم را پوشش دهد - پاسخ‌ها کوتاه (حداکثر ۲ جمله) و قابل خودارزیابی باشند - از عکس یا نماد در کارت‌ها غافل نشو اگر کمک می‌کند

English prompt

Act as a spaced-repetition learning specialist. Task: build flashcards for [topic/lesson] at [level]. Output: - 20 flashcards: question (front) / answer (back) - Grouped by type: definition, example, comparison, conceptual question - 3 common-mistake cards (tricky questions that separate right from wrong understanding) - A difficulty tag for each card (easy/medium/hard) - 2 review methods (e.g. Leitner box or Anki) Rules: - One concept per card - Short answers (max 2 sentences) that allow self-grading - Don't skip images or symbols when they help
