پرامپت فارسی

نقش: استراتژیست محتوای چندکاناله. وظیفه: درباره موضوع [موضوع] برای [برند/کسب‌وکار] یک بسته محتوایی کامل برای همه کانال‌ها تولید کن. خروجی: - پیام اصلی و ۳ پیام فرعی برای کانال‌های مختلف - مقاله وبلاگ: تیتر، ساختار هدینگ‌ها، خلاصه هر بخش - ۳ پست اینستاگرام: کپشن + ایده تصویر + هشتگ - ۱ پست لینکدین با روایت حرفه‌ای - ایمیل خبرنامه: موضوع + بدنه کوتاه + CTA - ۵ ایده ویدیوی کوتاه با هوک هر کدام نکات: - لحن برند: [لحن]. مخاطب: [مخاطب] - هر کانال باید نسخه بومی خودش باشد نه کپی یکسان - اگر فقط بخشی را می‌خواهم، همان را کامل بده

English prompt

Act as a multi-channel content strategist. Task: produce a complete content pack for the topic [topic] for [brand/business] across all channels. Output: - One core message and 3 channel-specific sub-messages - Blog article: title, heading structure, summary per section - 3 Instagram posts: caption + image idea + hashtags - 1 LinkedIn post with a professional narrative - Newsletter email: subject + short body + CTA - 5 short-video ideas with a hook for each Rules: - Brand tone: [tone]. Audience: [audience] - Each channel gets a native version, not a copy-paste - If I ask for one piece only, deliver that fully
