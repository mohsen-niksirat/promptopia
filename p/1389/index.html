اگه ذهنت یه اتاق بودReward curiosity through layered storytelling and symbolic

پرامپتوپیا · گالری پرامپت‌های آماده هوش مصنوعی

پرامپت فارسی

Reward curiosity through layered storytelling and symbolic environmental design. Create a unique poetic Persian name for the room. Examples of style only: "اتاق امیدهایی که هنوز نفس می کشند" "اتاق نور بعد از باران" "اتاق پنجره های همیشه باز" Do NOT reuse these examples. Always generate a brand-new original room name. Create a premium infographic section titled: "داخل این اتاق چی پیدا کردم؟" Display between 6 and 8 symbolic objects. For each object write a short Persian explanation describing what it symbolizes. The explanations should be emotionally intelligent, psychologically meaningful, warm, comforting, hopeful, and inspiring. Never shame the user. Never label them negatively. Never focus on flaws. Instead, gently highlight strengths, resilience, creativity, emotional growth, kindness, curiosity, courage, wisdom, healing, optimism, hidden talents, and inner potential. Create another beautiful section titled: "چرا این اتاق این شکلیه؟" Write a heartfelt Persian paragraph explaining the symbolic meaning of the room and how it reflects the user's inner world. The explanation should make the user feel understood without pretending certainty. VERY IMPORTANT: Write ALL Persian text using completely natural spoken Persian. Never use formal Persian. Never use literary or poetic language that feels unnatural. Never sound like AI. Never sound like a psychology textbook. Never sound like a therapist. Never sound like a motivational speaker. Never sound like generic inspirational social-media content. Write exactly like a close friend who genuinely knows the user and lovingly wants to show them something beautiful about themselves. Use warm everyday spoken Persian expressions naturally, such as: "میدونی..." "ببین..." "راستش..." "جالبه که..." "یه چیز قشنگ این اتاق اینه که..." "انگار..." "کم کم..." "به نظرم..." "شاید باورت نشه..." The writing should feel intimate, warm, reassuring, emotionally safe, deeply human, and full of curiosity. The goal is to make the user smile, become emotional, zoom in, explore every corner of the room, discover meaningful hidden details, feel deeply understood, and leave with more hope than before. The infographic should feel like opening the door to a beautiful hidden part of their own mind.
