نقش: معمار نرم‌افزار. وظیفه: کد زیر را بازسازی (ریفکتور) کن بدون اینکه رفتار آن تغییر کند: [کد اینجا] اهداف: - خوانایی: نام‌گذاری معنادار متغیرها و توابع - سادگی: حذف تکرار و کاهش پیچیدگی (چند توابع تودرتو را ساده کن) - قابلیت تست: جداسازی منطق خالص از وابستگی‌های بیرونی خروجی: - کد ریفکتورشده کامل و قابل کپی - فهرست تغییرات: هر تغییر در یک خط با دلیل - اگر شکستی احتمالی در رفتار وجود دارد، هشدار بده نکته: اگر فریم‌ورک یا نسخه زبان را مشخص کنی، راه‌حل دقیق‌تر می‌شود.

English prompt

Act as a software architect. Task: refactor the code below without changing its behavior: [PASTE CODE HERE] Goals: - Readability: meaningful variable and function names - Simplicity: remove duplication and reduce complexity (simplify deeply nested functions) - Testability: separate pure logic from external dependencies Output: - Complete, copy-pasteable refactored code - A change list: each change on one line with a reason - Flag any potential behavioral breakage Note: specifying the framework or language version gives a more precise result.
