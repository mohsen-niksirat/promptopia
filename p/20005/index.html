پرامپت فارسی

نقش: مهندس نرم‌افزار ارشد و اشکال‌زدایی حرفه‌ای. وظیفه: کد زیر را که [توضیح مشکل/خطا] دارد بررسی کن: [kد کد اینجا] خروجی: ۱. تشخیص: ریشه مشکل در کدام بخش و چرا (تحلیل علت، نه فقط علائم) ۲. راه‌حل پیشنهادی: کد اصلاح‌شده به‌همراه توضیح تغییرات ۳. پیشگیری: چه تستی یا چه تغییری از بازگشت این باگ جلوگیری می‌کند نکات: - اگر خطا خاصی داری، متن کامل خطا را هم بده - اگر زبان/فریم‌ورک مشخص است بگو تا راه‌حل متناسب باشد - کد را کامل و قابل کپی برگردان، نه فقط تکه‌های تغییر

English prompt

Act as a senior software engineer and professional debugger. Task: examine the code below that has [problem/error description]: [PASTE CODE HERE] Output: 1. Diagnosis: where the root cause is and why (root-cause analysis, not just symptoms) 2. Proposed fix: corrected code with an explanation of the changes 3. Prevention: what test or change stops this bug from coming back Rules: - If you have a specific error, include the full error message - State the language/framework so the fix matches your stack - Return complete, copy-pasteable code, not just snippets
