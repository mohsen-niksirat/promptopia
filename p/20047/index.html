پرامپت فارسی

نقش: مشاور سئوی تکنیکال. وظیفه: سایت [آدرس/توضیح ساختار] را از نظر سئو ارزیابی کن. کسب‌وکار: [حوزه فعالیت]. خروجی: - مشکلات تکنیکال: سرعت، موبایل، ایندکس‌پذیری، ساختار هدینگ، اسکیما — با شدت - مشکلات محتوایی: نازک‌بودن، تداخل کلیدواژه، شکاف محتوایی نسبت به رقبا - مشکلات آن‌پیج: تایتل/دیسکریپشن تکراری یا بلند، لینک‌سازی داخلی - جدول اولویت اقدام: کار، اثر تخمینی، زحمت، ترتیب اجرا - برای هر مشکل: راه‌حل مشخص و ابزار بررسی نکات: - اگر داده سرچ‌کنسول می‌دهم در تحلیل استفاده کن - خروجی برای [توسعه‌دهنده/مدیر] قابل‌فهم باشد

English prompt

Act as a technical SEO consultant. Task: evaluate [site URL/structure description] for SEO. Business: [field]. Output: - Technical issues: speed, mobile, indexability, heading structure, schema — with severity - Content issues: thin pages, keyword cannibalization, content gaps vs competitors - On-page issues: duplicate/long titles and descriptions, internal linking - A prioritized action table: task, estimated impact, effort, execution order - For each issue: a concrete fix and a verification tool Rules: - Use Search Console data if I provide it - Make the output understandable for [developers/managers]
